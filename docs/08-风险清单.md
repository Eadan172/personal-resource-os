# L. 风险清单

| # | 风险 | 等级 | 缓解措施 |
|---|---|---|---|
| R1 | Obsidian 闭源 + 社区插件供应链（REF6598 已实证社工攻击链） | 高 | 插件白名单；自研薄插件；vault 无密钥；禁用命令执行类插件 |
| R2 | 第三方 MCP Server 漏洞面大（路径穿越等） | 高 | 全部视为不可信输入；Gateway 策略强约束；契约测试 |
| R3 | LLM 幻觉进知识库 | 高 | 五类 origin 区分；推断不伪装事实；关系默认 suggested；RAG 无证据拒答 |
| R4 | AI 写操作破坏数据 | 高 | content 字段 schema 级禁 AI 写；全 mutation 审计 + 回滚；删除=软删除 |
| R5 | 密钥泄露（日志/DB/prompt） | 高 | OS secret store；日志脱敏；密钥永不进模型上下文；出站 allowlist |
| R6 | “Jev模型”含义未确认 | 中 | 抽象为可插拔 Decision Evaluation Model（ADR-007），等用户确认后实现 |
| R7 | WorkBuddy/ima 官方 API 演进不稳定 | 中 | Connector 可替换设计；契约以接入时最新官方文档为准；不绑死核心模型 |
| R8 | MCP 规范大版本迁移（2026-07-28 无状态化，12 个月弃用窗口） | 中 | Gateway 直接按新版实现；跟踪 SDK 版本；向后兼容层隔离 |
| R9 | 中文 FTS 分词质量 | 中 | MVP 用 unicode61+预处理；V1 换 jieba/ICU；向量召回兜底 |
| R10 | 个人项目维护成本失控 | 中 | 薄适配层 + 自有核心；第三方代码能删就删；复用成熟组件 |
| R11 | 多模态转写/OCR 质量与成本 | 中 | 一期只做保存+转写+摘要；本地模型可选；衍生数据带 processor_version 可重跑 |
| R12 | 备份不可用（写了但没验证） | 中 | restore 测试纳入 CI；备份含 manifest 哈希校验 |
| R13 | Agent 死循环/费用失控 | 中 | max_steps/timeout/token/retry/depth 硬限制 + 测试覆盖 |
| R14 | AGPL 组件误用导致许可义务 | 低 | 不 fork、不链入 AGPL 代码；只参考设计 |
