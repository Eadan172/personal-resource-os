# E. 核心数据模型

原则：通用 Object Model；原始事实 / 用户编辑 / AI 提取 / AI 推断 / AI 建议五类来源严格区分；一切结构化字段可回溯到来源文本片段。

## 1. 统一对象（objects 表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | TEXT (ULID) | 主键 |
| type | TEXT | note/idea/task/person/project/event/bookmark/document/meeting/conversation/topic/concept/decision/risk/money/location |
| title | TEXT | 标题（AI 可生成，标记 origin） |
| content | TEXT | **原始内容，写入后不可被 AI 覆盖**（用户可编辑，产生新 revision） |
| source_uri | TEXT | 来源（文件路径/URL/渠道标识） |
| content_hash | TEXT | SHA-256，去重与完整性校验 |
| origin | TEXT | raw（原始事实）/ user_edit / ai_extracted / ai_inferred / ai_suggested |
| confidence | REAL | AI 结果置信度 0–1；raw/user_edit 恒为 1 |
| provenance | JSON | `{processor, processor_version, source_object_id, spans:[{start,end}]} ` 证据偏移 |
| tags | JSON 数组 | |
| properties | JSON | 类型特定字段（任务字段、人物字段等） |
| event_time_start/end | TEXT | 事件时间（与记录时间分开建模，选择 31-D） |
| lifecycle | TEXT | inbox / processed / archived / deleted（软删除，可恢复） |
| created_at / updated_at | TEXT | ISO8601 |

## 2. 关系（relations 表）

| 字段 | 说明 |
|---|---|
| id / src_id / dst_id | 主键与两端对象 |
| type | related_to / mentions / belongs_to / assigned_to / depends_on / derived_from / contradicts / supports / duplicate_of / references |
| status | **suggested（AI 建议，默认）/ confirmed（用户审核通过）/ rejected** |
| confidence / provenance | AI 建关系必带置信度与证据 |
| created_at | |

规则：AI 只写 `suggested`；`duplicate_of` 只提示不自动合并（选择 17-B）。

## 3. 任务（tasks 表）

title、source_object_id（来源对象）、due_at、priority（P0–P3）、status（todo/doing/done/cancelled）、project、assignee、tags、created_at、completed_at、provenance、confidence、**created_by_agent（0/1）**、audit trail（经 audit_log 关联）。

## 4. 衍生数据（extractions 表）

多模态统一：原始文件永远保留在文件仓库；解析结果/Transcript/OCR/网页正文作为衍生数据：

| 字段 | 说明 |
|---|---|
| id / source_object_id | 关联原始对象 |
| kind | transcript / ocr / web_text / pdf_text / summary / entities |
| content | 衍生内容 |
| content_hash / processor / processor_version / created_at | 全部必填（§七要求） |

## 5. 审计（audit_log 表）

| 字段 | 说明 |
|---|---|
| id | |
| op | create / update / delete / restore |
| object_type / object_id | |
| before / after | JSON 快照（diff 的基础） |
| actor | user / agent:{name} / connector:{name} |
| agent_run_id | 关联 agent_runs |
| reversible | 0/1 |
| created_at | |

回滚：对 create 回滚 = 软删除；对 update 回滚 = 恢复 before；对 delete 回滚 = restore。`content` 原始字段的 AI 写入被 schema 层直接拒绝。

## 6. Agent 定义与运行（agents / agent_runs / approvals 表）

- agents：name、purpose、instructions、allowed_tools(JSON)、allowed_scopes(JSON)、provider/model、trigger(`manual|event:inbox|cron:...`)、output_schema、approval_policy(`auto|confirm|deny` per action class)、budgets（max_steps/timeout_s/max_tokens/max_retries/max_depth）。
- agent_runs：status（running/succeeded/failed/aborted_budget/aborted_timeout/waiting_approval）、steps、tokens_used、started_at/finished_at、error。
- approvals：agent_run_id、action(JSON)、status（pending/approved/rejected）、decided_at。敏感操作未批准不执行。

## 7. 索引

- `objects_fts`：SQLite FTS5（title, content, 衍生文本），支持中文（unicode61 + 自研分词预处理，V1 可换 jieba/ICU）。
- 向量索引（V1）：embeddings 表（object_id, chunk_no, vector BLOB, model），检索时与 FTS 做 RRF 融合。
- 元数据/时间过滤直接走 objects 字段索引。

## 8. 导出/备份

- JSON 导出：objects + relations + tasks + extractions + audit_log 全量，带 schema_version。
- 备份：SQLite 在线备份 + 文件仓库打包 + manifest（含 SHA-256 清单）；restore 校验 manifest 与 migration 版本。
