# ADR-005 审计 / Diff / 回滚设计

- 状态：已接受  日期：2026-09-29
- 决定：单一 audit_log 表记录所有 mutation 的 before/after JSON 快照 + actor + agent_run_id；rollback 按 op 取逆（create→软删除、update→恢复 before、delete→restore）；删除一律软删除（lifecycle=deleted）。`objects.content` 在 schema 层禁止 AI origin 写入。
- 理由：满足 12-D/47-D；快照式 diff 实现最简单且可靠，MVP 不引入事件溯源的复杂度。
- 后果：audit_log 会膨胀，V1 加归档/压缩策略。
