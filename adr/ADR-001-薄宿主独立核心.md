# ADR-001 薄宿主 + 独立 Agent Core + MCP Gateway

- 状态：已接受  日期：2026-09-29
- 背景：52 题最终确定 F；要求核心领域模型不绑定 Obsidian/微信/WorkBuddy/ima。
- 决定：Obsidian 仅作薄宿主（编辑/展示），全部领域逻辑在独立 Python 进程 Personal Agent Core；外部渠道经 MCP Gateway + 可替换 Connector 接入。
- 理由：候选底座均不适合 fork（闭源/AGPL/架构重/有 RCE 前科，见 docs/02）；独立核心是唯一的长期资产。
- 后果：需要自研闭环管道（已在 MVP 范围）；宿主插件极薄，替换宿主成本低。
