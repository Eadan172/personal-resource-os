# ADR-004 混合检索：FTS5 优先，向量后置

- 状态：已接受  日期：2026-09-29
- 决定：MVP 用 SQLite FTS5（unicode61 + 中文预处理）+ 元数据过滤 + 时间过滤 + 规则 rerank；Embedding/Reranker 走 Provider Adapter 接口预留，V1 以 RRF 融合向量召回。
- 理由：28-G 要求 Keyword+Semantic+Metadata 混合，但 MVP 需要离线确定性；FTS5 零外部依赖、可测、可解释。向量依赖模型下载/外发，后置不阻塞闭环。
- 后果：纯语义召回（无关键词重叠）在 MVP 较弱，V1 补齐。
